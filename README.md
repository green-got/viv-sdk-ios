# Green-Got VIV iOS SDK

Binary distribution of VivSDK 0.1.0. Requires iOS 14 or newer.
Add `https://github.com/green-got/viv-sdk-ios.git` as a Swift Package Manager dependency,
select version `0.1.0`, then `import VivSDK`.

Documentation: https://ggbs.gg/viv/documentation/

The SDK sources are private. Public Swift interfaces describe the API; they
are not the implementation. The native Green-Got capture engine still needs
to be connected to the capture interface. A configured GGBS backend and capture
implementation are required for facial verification. See the publisher's SDK
terms before use.

SDK terms: https://ggbs.gg/viv/tos/2026-09-20
